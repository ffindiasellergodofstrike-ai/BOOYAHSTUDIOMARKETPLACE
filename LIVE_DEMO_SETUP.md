# Product previews

Public previews are in `public/demos/<product-id>/`. Paid source archives belong in the private Supabase `products` bucket. Do not copy archives into public preview folders.

The 20 static sources in `templates/` have four pages each and their own README/license. Public demos add a preview label. The retired WorkHub preview is preserved in `owner-files/workhub-demo` and is not served by the deployed site.

Before publishing a new listing, provide accurate included files, version, requirements, dependencies, limitations and license. Add a matching private ZIP; test the preview and protected download separately.
